# 🏠 SuperKost : Kost & RooMatch Finder

SuperKost adalah aplikasi pencarian hunian yang membantu pengguna menemukan kos, kontrakan, atau apartemen sesuai kebutuhan, sekaligus menyediakan fitur pencarian roommate berdasarkan preferensi pengguna.

Proyek ini dikembangkan sebagai Tugas Besar Mata Kuliah Pemrograman Berorientasi Objek (PBO) dengan menerapkan konsep Object-Oriented Programming (OOP) seperti Encapsulation, Inheritance, Polymorphism, Collection Framework, Exception Handling, dan Design Pattern.

---

## ✨ Fitur Utama

### 🔍 Pencarian Hunian
- Smart Filter berdasarkan harga, lokasi, fasilitas, dan tipe hunian
- Smart Sorting berdasarkan harga, jarak, dan rating
- Perbandingan beberapa hunian
- Real-time Map View

### 👥 Roommate Matching
- Roommate Survey
- Roommate Request
- Chat antar pengguna

### 🏢 Manajemen Properti
- Tambah data hunian
- Edit data hunian
- Hapus data hunian
- Monitoring status hunian

### ⭐ Fitur Tambahan
- Login & Registrasi
- Wishlist / Favorit Hunian
- Review & Rating
- Notifikasi Sistem
- Pengelolaan Profil
